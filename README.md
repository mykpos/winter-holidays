# Winter holidays

A Christmas and winter theme for Claude Desktop: a snowy valley with a cabin, a decorated tree and a garland of lights, falling snow, Santa flying by on his sleigh, and shooting stars across the northern lights at night. Chat bubbles are festive red and green, and soft bells ring for sends, tool calls and replies.

Light mode shows a frosty day; dark mode shows a moonlit night. The scene respects reduced-motion settings.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install winter-holidays --marketplace mykpos/winter-holidays
```

Answer `y` to add the marketplace, then press Enter to pick the user scope.

From a shell:

```
claude plugin install winter-holidays --marketplace mykpos/winter-holidays
```

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace with `mykpos/winter-holidays`, then Add plugin.
